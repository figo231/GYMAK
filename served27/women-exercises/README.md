# Original GYMAK exercise illustrations

These 36 start/end frames are original programmatic drawings made for GYMAK.
They contain no third-party photos, traced images, or imported artwork.
The reproducible drawing source is scripts/generate-women-illustrations.py.
They use two-frame animation, not video or motion capture. They are simplified
illustrations and should be used alongside the written exercise instructions.
No claim is made about the copyright status of older exercise photos elsewhere
in the app. Those are not part of this original illustration set.
